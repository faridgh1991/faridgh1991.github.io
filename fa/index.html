توسعه‌دهنده ارشد نرم‌افزار در Ring

سامانه‌های بک‌اندی سریع، دقیق و قابل نگهداری در مقیاس بالا.

فرید قورچیان هستم، توسعه‌دهنده ارشد نرم‌افزار ساکن تهران. سرویس‌های بک‌اند را با Go و Python طراحی و پیاده‌سازی می‌کنم؛ از طراحی API و معماری توزیع‌شده تا بهینه‌سازی کارایی و نگهداری روزمره در محیط عملیاتی. در Ring روی بک‌اند یک پلتفرم آگهی کار می‌کنم که خریداران و فروشندگان را به هم وصل می‌کند.

تماس با من مشاهده پروژه‌ها
Go و Python زبان‌های اصلی برای سرویس‌ها، APIها، ابزارها و پردازش داده.
سیستم‌های توزیع‌شده مایکروسرویس‌های هم‌زمان بر پایه Kafka، PostgreSQL و Linux.
پایداری در اولویت درستی، مشاهده‌پذیری و کارایی به‌عنوان بخشی از محصول، نه کاری برای بعد.
تهران، ایران

فرید قورچیان

توسعه‌دهنده ارشد نرم‌افزار با تجربه در پلتفرم‌های آگهی، تبلیغات آنلاین و Billing مخابراتی، و مشارکت فعال در پروژه‌های متن‌باز Go و Linux.

  • Go
  • Python
  • C/C++
  • Kafka
  • PostgreSQL
  • Linux
  • Microservices
  • Backend APIs

درباره من

تخصص من مهندسی بک‌اند برای محصولاتی است که هم درستی و هم ظرفیت پردازش در آن‌ها اهمیت دارد. تمرکزم روی مرزبندی روشن سرویس‌ها، APIهایی که بدون شکستن کلاینت‌ها قابل توسعه باشند و انتخاب‌های زیرساختی است که بار عملیاتی را واقعاً کم کنند، نه این‌که آن را جابه‌جا کنند.

روی سامانه‌های آگهی، تبلیغات آنلاین و Billing مخابراتی کار کرده‌ام؛ حوزه‌هایی با نیاز گسترده به یکپارچه‌سازی و تحمل بسیار کم برای قطعی. دیباگ منظم و ترجیح طراحی‌های ساده‌ای که کل تیم بتواند آن‌ها را بفهمد و نگهداری کند، بخشی از روش کار من است.

تخصص‌ها

  • زبان‌ها: Go و Python به‌عنوان زبان‌های اصلی؛ همچنین C، C++، Java و Clojure.
  • معماری: سیستم‌های توزیع‌شده، مایکروسرویس‌ها، سرویس‌های هم‌زمان و طراحی API بک‌اند.
  • داده و پیام‌رسانی: Kafka، PostgreSQL و پردازش رویدادمحور.
  • حوزه‌ها: پلتفرم‌های آگهی، تبلیغات آنلاین، Billing مخابراتی و RADIUS.
  • روش کار: گردش‌کار مبتنی بر Linux، DevOps عمل‌گرا، مشاهده‌پذیری و پروفایل‌گیری کارایی.

سوابق کاری

Ring توسعه‌دهنده ارشد نرم‌افزار · فعلی طراحی و نگهداری سرویس‌های بک‌اند یک پلتفرم آگهی که خریداران و فروشندگان را به هم وصل می‌کند، با تمرکز بر پایداری و کارایی زیر بار.
SabaVision مهندسی بک‌اند · تبلیغات آنلاین توسعه و راهبری سرویس‌های بک‌اند یک شبکه تبلیغاتی، با تاکید بر پایداری سرویس و تحویل در مقیاس بالا.
Parspooyesh توسعه نرم‌افزار · مخابرات و Billing مشارکت در IBSng، سامانه Billing سازمانی، و Rebin، پلتفرم مخابراتی مبتنی بر RADIUS، که پایداری و یکپارچه‌سازی در آن‌ها حیاتی بود.
متن‌باز مشارکت‌کننده و نویسنده مشارکت در پشتیبانی سخت‌افزار در Linux (OpenRazer و libratbag) و کتابخانه RADIUS برای Go، و نویسنده چند پکیج منتشرشده Go.

پروژه‌های منتخب

محصولات

  • Ring پلتفرم آگهی رایگان برای ارتباط خریداران و فروشندگان.
  • SabaVision شبکه تبلیغاتی: سرویس‌های بک‌اند و زیرساخت تحویل.
  • IBSng سامانه Billing سازمانی برای اپراتورهای شبکه و مخابرات.
  • Rebin محصول زیرساخت مخابراتی مبتنی بر RADIUS.

متن‌باز

  • Samsa کتابخانه کلاینت Kafka برای Go. نویسنده.
  • Sqids-WASM تولید شناسه کوتاه یکتا با خروجی WebAssembly. نویسنده.
  • Numero-Go کلاینت Go برای اتصال به درگاه پیامک ایرانی. نویسنده.
  • MagfaGo کلاینت Go برای سرویس پیامک Magfa. نویسنده.
  • layeh.com/radius پیاده‌سازی پروتکل RADIUS برای Go. مشارکت‌کننده.
  • OpenRazer درایورهای Linux برای تجهیزات Razer. مشارکت‌کننده.
  • libratbag سرویس پیکربندی تجهیزات ورودی در Linux. مشارکت‌کننده.
